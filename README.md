# Project Mosaic

This is a customisable to-do list made for my Integrative Programming Class. At the same time, it's also under Project Sandstorm - a long term initiative to unite all my creative work with tech solutions.

It has 3 modules:
- Settings.js handles mostly wallpaper stuff.
- Tabs.js handle tab creation and removal
- ToDo.js handle todo list and it's data
- Load.js handle task loading, modification, saving and attachment CRUD.
